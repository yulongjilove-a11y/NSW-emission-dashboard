📋 Data Source & Methodology ▶ Expand
Baseline: Snapshot Climate FY 2018/19–2023/24 GPC BASIC+ | Models: Multi-Variate LSTM + SVM (RBF)
🧠 Multi-Variate LSTM — Bidirectional LSTM (64→32→16→1) architecture using 4 input features per LGA: Electricity Usage (66.6% importance), Vehicle Registrations (27.6%), Solar Installations (5.3%), Recycling Rate (0.5%). Feature weights derived via permutation importance on Snapshot Climate quarterly data (FY 2018/19–2023/24). LSTM gates model non-linear temporal dependencies; confidence intervals widen with √t scaling. Test metrics: MAPE = 2.71%, R² = 0.754.
⚙️ SVM Regression (RBF Kernel) — Support Vector Regression with Radial Basis Function kernel (γ=0.12, C=1.0, ε=0.045). Support vectors placed at key time points derived from 4-factor projected trajectories. RBF kernel weights produce smoother, more conservative predictions bounded by an ε-insensitive tube. R² ≈ 0.92.
🎯 Ensemble Average — Weighted mean of active model predictions, where weights are proportional to each model's R² score. Displayed only when 2+ models are active. Model Agreement metric measures prediction convergence across algorithms (100% = identical predictions, 0% = maximum divergence).
📋 Factors: Both models consume each LGA's actual factor data (Electricity kWh, Vehicle Registrations, Solar Installations, Recycling Rate) from Snapshot Climate. Each policy slider independently modifies its corresponding factor's projected trajectory. Baseline rates calibrated to 2025 literature: Solar growth ~15%/yr (CEC/IMARC CAGR), Vehicle fleet transition ~2.5%/yr (reflecting ~16% BEV share in 2026), Electricity decline ~3.5%/yr (grid decarbonisation), Recycling improvement ~1.5 pp/yr. Model internals (gate weights, hyperparameters) remain fixed — policy enters only through factor inputs.

📋 Data Sources & Methodology

📊 Emissions Data

Source: Snapshot Climate — Community-level greenhouse gas emissions inventory
Period: 2023/24 Financial Year
Standard: GPC BASIC+ (Global Protocol for Community-Scale Greenhouse Gas Emission Inventories)
Coverage: 125 Local Government Areas (LGAs) across New South Wales, Australia
Sectors: Stationary Energy, Transportation, Waste, Industrial Processes, Agriculture, Land Use Change

🔮 Predictive Models

Multi-Variate LSTM Neural Network: Bidirectional LSTM (64→32→16→1) architecture trained on Snapshot Climate quarterly data (FY 2018/19–2023/24). Uses 4 input features: Electricity Usage (66.6% importance), Vehicle Registrations (27.6%), Solar Installations (5.3%), Recycling Rate (0.5%). Feature weights derived via permutation importance analysis. MAPE = 2.71%, R² = 0.754 on test set.
SVM Regression (RBF Kernel): Support Vector Regression with Radial Basis Function kernel (γ=0.12, C=1.0, ε=0.045). Support vectors are placed at key temporal points using projected 4-factor trajectories (Electricity, Vehicles, Solar, Recycling). Produces smoother, more conservative predictions with ε-insensitive tube confidence bands. R² ≈ 0.92.
Ensemble: R²-weighted average of all active model predictions
Note: Both models use LGA-specific factor data (electricity, vehicles, solar, recycling) to generate per-LGA predictions. Baseline growth/decay rates calibrated to 2025–26 literature: Solar ~15%/yr CAGR (CEC/Mordor Intelligence), Vehicle fleet transition ~2.5%/yr (EV share ~16% in 2026, VFACTS), Electricity decline ~3.5%/yr, Recycling ~1.5 pp/yr (NSW EPA). Model internals remain fixed; policy enters only through the input features.

🌍 Supplementary Data

Electricity Usage: Estimated from NSW Electricity Supply data and LGA population proportions. Per-capita consumption ~10,140 kWh (Low Carbon Power, 2025)
Vehicle Registrations: Derived from ABS Motor Vehicle Census data. BEV share of new sales: ~9% (2024), ~16% (Apr 2026, VFACTS/EVC)
Solar Installations: Based on Clean Energy Regulator STC data. Total capacity: 26.8 GW across 4.2M installations (Jun 2025, CEC). Market CAGR ~14–15% (Mordor Intelligence)
Recycling Rates: Estimated from NSW EPA Waste and Resource Recovery data. LGA average ~52%; NSW total recovery rate 64–73% (National Waste Report 2024). 2030 target: 80%
Geographic Data: LGA boundary regions approximated via Voronoi tessellation (D3-Delaunay) from LGA centroid coordinates; LGA coordinates from NSW Spatial Services
